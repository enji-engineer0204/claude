なぜ今、うちで

「作れる速さと質」が、そのまま競争力になっている。

トライリンクスは、業務特化AIエージェント開発・推進(SUISHIN)・AIキャラ／音声AI・ハンズオン研修を手がける会社。 強みは数日単位の開発スピード。だが世の中では AIエージェントの約72%がPoC（お試し）止まりで本番に乗らない。 差がつくのは「導入」ではなく定着——つまり、全員が日常業務で当たり前に使えているか。この資料はそのための共通言語です。

方針：躊躇っている前提にしない。「みんな使っている前提で、そこにプラスアルファ」で話す（社内アンケート「質問一覧」で決めた方針を踏襲）。

結論

伸びる人のAIの使い方は「7つの型」に集約される。

長島が実際にトライリンクス業務でAIと作った成果物・運用記録から抽出。 全部「AIが賢いか」ではなく頼み方・使い切り方・組み込み方の話＝才能でなく型なので、教育できる。

TYPE 01

チャットで終わらせず「動くもの」を作り切る

質問でなく、業務が回るツール／パイプラインまで。

実例ai-news-tuber：ニュース→AI解説ショート動画を自動生成する7段パイプライン（npm run pipeline一発）

TYPE 02

繰り返し作業を「コマンド／仕組み」に変える

一度作れば、全員が一言で同じ品質を呼べる。

実例/議事録 /日報 コマンド・自作のNotionタスク生成スキル。「人によって出力バラバラ／保存先が散る」を潰す

TYPE 03

手動MVP→半自動→全自動の順で出す

まず手で回して価値検証、それから自動化。

実例商談→改善点AI：先にDBだけ作り手入力→効くと確認→段階的に自動化

TYPE 04

セキュリティ・権限・法務を「最初」に設計

秘密・公開範囲・規約・上限を先に決める。

実例APIキーは.env分離／公開範囲でDB分離＋コードネームTL-###／AI生成表記／予算上限5万円

TYPE 05

丸投げせず「ガードレールと検証」を敷く

検証・dry-run・人の最終レビューを挟む。

実例スキーマ・禁止語句検証／--dry-run／指数バックオフ／権限は確認モード／本番前に自分の手で動作検証（runbook）

TYPE 06

引き継げる「文脈ドキュメント」を残す

属人化を防ぎ、未来の自分とAIに渡す。

実例CLAUDE.md／ハンドオフ文書／実行ログ（いつ何を決め、どう方針転換したか）

TYPE 07

結果を「普段見る場所」に流し、道具は使い分ける

通知先も、モデルも、目的で選ぶ。

実例Slack／Discord／Notionへ自動通知。リスク判定=Opus・生成=Sonnet。手段は調べ直して更新（Chrome想定→公式MCPへ）

USE IT

この型は「教育できる」

才能ではなく手順。だから配れる。次ページから、実例と"明日から使える頼み方"に落とします。

合言葉AIは"賢い相談相手"でなく"作ってくれる部下"。最後まで作らせる。

明日から

コピペで使える「頼み方テンプレ」

「何をどう頼めばいいか分からない」を潰す3枚。社内の実タスクで書き換えて使う。

浸透メソッド

「説明」より「一緒にやる」。1業務を片付けて体感させる。

これは長島が実際に社外ワークショップで使っている型。そのまま社内に効く。

体感ドリブンの回し方（西武WS 当日ガイドより）

  • 説明は5分以内。あとは画面共有で見せる＆一緒にやる（4見せる：6手を動かす）
  • 相手に「どう指示します？」と振る。見てるだけにさせない
  • 各デモで「今まで何分？→今◯分」と時間を言ってもらう（＝ROIを本人の口から）
  • ゴールは実業務を1つAIで片付けて腹落ち→「社内で広げたい」まで

ロードマップ

点火 → 各自1個 → 型化 → 資産化

PHASE 01

点火

実例をデモし、各自の"面倒ごと"を1つ書き出す。「うちのAIで何ができるか」を体感。

PHASE 02

各自1個

全員がテンプレAで自分の面倒ごとを1つ自動化。相談窓口（Slack）＋小さな成功体験。

PHASE 03

型化・共有

良い頼み方をコマンド化して横展開。プロンプト集・5分動画・部署別活用事例。

PHASE 04

資産化

秘密情報・AI表記・承認ラインを全社ルール化。文脈ドキュメント文化を標準に。

勘所：①点火で終わらせず、②"全員が自分の1個を持つ"まで落とすのが分かれ目。社内アンケート「質問一覧」の設問がそのまま①②のネタ出しに使えます。

想定される不安

ためらいの理由に、先に答えておく。

うまく指示できるか不安
良い指示はコマンドに固めて配る（型2）。普段の言葉で呼ぶだけの状態を作る。
忙しくて学ぶ時間がない
まず1個だけ（テンプレA）。手動MVPは"手作業＋AIに一言"から始められる。
自分の業務で使うシーンが浮かばない
"面倒ごと書き出し"から。議事録・日報・転記など、全員に必ずある。
精度・セキュリティが不安
型4・型5。秘密を先に分離し、出す前に検証・人がレビューすれば安全に前進できる。
回答がイマイチだった
諦めず頼み方を変えて再挑戦。出力は"たたき台"前提で、選ぶ・直す工程を持つ。
